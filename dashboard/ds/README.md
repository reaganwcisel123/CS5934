# Vendored design-system assets

Self-contained subset that `../clinic-needs-atlas-signal.html` loads at runtime:
the compiled component bundle (`_ds_bundle.js`), the token stylesheet
(`styles.css`), and its `tokens/`. Copied from the "Triad Health Engine Design
System" source kit, which is kept out of the repo.

To refresh, re-copy `styles.css`, `_ds_bundle.js`, and `tokens/*.css` from that kit.

# Synthetic Clinical Dataset

This dataset is generated by `src/ingestion/synthetic_clinical.py` and is intentionally synthetic and non-PHI.

## Purpose
- Support dashboard development and prototype modeling without using real patient data.
- Provide a reproducible synthetic patient roster keyed by `county_fips`.
- Preserve clinical-looking fields while avoiding any real patient identifiers.

## Generation
- Each county generates 3-4 synthetic patients deterministically, seeded from `county_fips`.
- Patient records include vitals, a recent visit date, a social needs struggle, and a preventable hospitalization risk flag.
- Synthetic patient records are joined with county-level SDoH context during dataset build.

## Provenance
- `provenance` in the dataset marks this source as `synthetic`.
- The source is cataloged as `synthetic_non_phi` and must never be treated as real patient data.
